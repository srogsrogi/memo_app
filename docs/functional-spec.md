# 📋 기능정의서 (Functional Specification)

메인 보드를 제거한 **100% 바탕화면 스티커 중심 구조**와 **일반 메모(`memo`) / 할 일(`todo`) 분리 규격**, 그리고 구현된 모든 세부 기능을 정의합니다.

---

## 1. 핵심 설계 원칙 요약

| 구분 | 확정 규격 |
| :--- | :--- |
| **윈도우 구성** | 모든 활성 카드는 **바탕화면 프레임리스 스티커 창**으로만 존재 (최대 10개 제한, ±14px 자석 스냅 지원). 보조 창으로 시스템 트레이/메뉴바에서 열리는 **'완료 아카이브 & 설정' 미니 창 (420×540px, 3개 탭 구성)** 단 1개만 사용 |
| **일반 메모 (`memo`)** | 자유 마크다운 에디터(`Tiptap`). 별도 제목칸 없이 첫 줄부터 바로 작성. 로그나 휴지통 없이 `🗑️` 클릭 시 3초 인라인 실행 취소 카운트다운 후 영구 삭제 |
| **할 일 (`todo`)** | 전용 투두 리스트 컴포넌트. 상단 그룹 제목란(기본값: `"할 일"`) + **상단 고정 새 할 일 입력창**(`Enter` 시 리스트 **맨 아래**에 순서대로 추가). 각 줄마다 **`[✓ 완료]`**(활성 리스트에서 즉시 제거 및 완료 시각과 함께 아카이브 로그에 기록), **`[× 삭제]`**(로그 없이 단순 제거), **`[▲/▼ 순서 재배치]`**, **`[📅 만료일 설정]`** 지원 |
| **스티커 툴바** | `➕` 현재 창과 동일한 타입(`memo`면 새 메모, `todo`면 새 할 일)으로 1클릭 즉시 생성, `📌` 항상 위 토글, `🎨` 4종 테마 색상(`yellow`, `mint`, `pink`, `purple`) 변경, `🗑️` 스티커 삭제 (3초 실행 취소 오버레이) |
| **더블클릭 접기** | 스티커 상단 드래그 바 더블클릭 시 **높이 38px 미니 바**로 접기/펼치기 (`memo`: 첫 줄 요약 표시 / `todo`: `그룹 제목 (남은 N건)` 표시) |
| **크로스플랫폼 OS 감지** | Windows 및 macOS 동적 감지. macOS에서는 메뉴바 상주 + Dock 클릭 시 메인 창 활성화 + `Cmd+Shift+N/T` 단축키 + `macOS 로그인 시 자동 실행` 맞춤 제공 |

## 2. 도메인별 상세 기능 요구사항

### 2.1 스티커 노트 창 기능 (Sticky Window Domain)

| 기능 ID | 기능명 | 동작 규격 및 조건 분기 | 우선순위 |
| :--- | :--- | :--- | :---: |
| **FN-STK-01** | **프레임리스 창 및 상단 미니 툴바** | - OS 기본 타이틀바가 제거된 파스텔 포스트잇 스타일 디자인 적용<br/>- 창 상단 호버/포커스 시 미니 툴바 표시: `➕ 동일 타입 스티커 추가`, `🎨 색상 변경`, `📌 항상 위 토글`, `🗑️ 스티커 삭제`<br/>- 최대 활성 스티커 개수는 **10개**로 제한(10개 도달 시 `➕` 버튼 비활성화 및 안내 토스트 표시) | **P0** |
| **FN-STK-02** | **`➕` 동일 타입 스티커 1클릭 생성** | - 메모 스티커에서 `➕` 클릭 시: 새 일반 메모(`memo`) 스티커 창을 즉시 생성하여 우측 대각선(+24px, +24px) 위치에 띄우고 커서 포커스<br/>- 할 일 스티커에서 `➕` 클릭 시: 새 할 일(`todo`) 스티커 창을 즉시 생성 | **P0** |
| **FN-STK-03** | **`🗑️` 스티커 삭제 및 3초 실행 취소** | - 툴바 `🗑️` 클릭 시: 스티커 내부 영역이 `"삭제되었습니다 [↩️ 실행 취소] (3s)"` 오버레이로 전환됨<br/>- 3초 이내에 `[↩️ 실행 취소]`를 클릭하면 정상 상태로 복귀<br/>- 3초가 지나면 창이 닫히며 로컬 `notes.json`에서 완전히 영구 삭제되고 Gist 파일 삭제 예약 | **P0** |
| **FN-STK-04** | **항상 위(Always-on-Top) 고정 토글** | - `📌` 버튼 클릭 시 `alwaysOnTop` 상태를 토글하며, Electron `setAlwaysOnTop(flag, 'floating')` 실행<br/>- 고정 상태는 해당 기기 로컬 설정(`device-config.json`)에 즉시 저장 | **P0** |
| **FN-STK-05** | **상단바 더블클릭 접기 (미니모드)** | - 상단 드래그 바를 더블클릭하면 높이 38px의 얇은 바 형태로 축소 (`isCollapsed = true`)<br/>  • `memo` 접힘 시: 본문 첫 번째 줄 텍스트를 헤더에 표시<br/>  • `todo` 접힘 시: `그룹 제목 (남은 N건)` 형태로 표시<br/>- 다시 더블클릭하면 원래 크기(`height`)로 즉시 복원 | **P0** |
| **FN-STK-06** | **창 좌표 및 크기 기기별 자동 기억** | - 스티커 창을 이동하거나 모서리를 드래그해 크기를 변경하면 디바운스(250ms) 후 `device-config.json`에 `x, y, width, height` 저장<br/>- 앱 재시작 시 저장된 좌표로 정확히 복원하며, 외부 모니터 분리로 인해 화면 밖으로 벗어난 좌표는 주 모니터 영역 내부로 자동 보정(Clamping) | **P0** |
| **FN-STK-07** | **창 모서리 및 스티커 간 자석 스냅 (Magnetic Snapping)** | - 창을 드래그하여 이동할 때, 화면 가장자리(작업 영역) 및 다른 열려 있는 스티커 창 모서리와 거리가 **±14px 이내**로 근접하면 딱 달라붙도록 좌표를 자동 보정 | **P1** |

### 2.2 에디터 & 투두 리스트 기능 (Editor Domain)

| 기능 ID | 기능명 | 동작 규격 및 조건 분기 | 우선순위 |
| :--- | :--- | :--- | :---: |
| **FN-EDT-01** | **📝 일반 메모: Tiptap 마크다운 에디터** | - 별도 제목칸 없이 첫 줄부터 자유롭게 타이핑 시작<br/>- `# ` 헤딩, `**텍스트**` 굵게, `~~텍스트~~` 취소선, `` `코드` `` 인라인 코드, `- ` 글머리 기호 목록 자동 렌더링<br/>- 내용이 창 높이를 초과하면 내부 스크롤바 표시 | **P0** |
| **FN-EDT-02** | **☑️ 할 일: 상단 그룹 제목 및 상단 고정 입력창** | - 최상단: 그룹 제목 입력란 (기본 placeholder: `"제목"`, 비어 있을 시 기본 그룹명 `"할 일"`로 취급)<br/>- 그룹 제목 바로 아래: **새 할 일 입력창 고정 배치** (할 일 타이핑 후 `Enter` 입력 시 리스트 **맨 아래에 순서대로 추가**되며 입력창은 즉시 공백으로 초기화)<br/>- 우측 📅 달력 아이콘을 눌러 추가 전에 만료일을 미리 지정 가능 | **P0** |
| **FN-EDT-03** | **☑️ 할 일: `[✓ 완료]` (아카이빙) vs `[× 삭제]`** | - **`[✓ 완료]` 버튼 클릭**: 클릭 즉시 활성 리스트에서 제거되며, `completedAt = Date.now()` 타임스탬프와 함께 **완료 아카이브(`archive.json`)에 즉시 추가**<br/>- 완료 직후 스티커 하단에 3초간 `[완료되었습니다 | 실행 취소]` 미니 토스트 표시<br/>- **`[× 삭제]` 버튼 클릭**: 잘못 작성한 항목이므로 아카이브에 남기지 않고 즉시 영구 제거 | **P0** |
| **FN-EDT-04** | **4종 테마 컬러 팔레트** | - 노란색(`yellow`), 민트(`mint`), 핑크(`pink`), 퍼플(`purple`)<br/>- 색상 변경 시 모든 열려 있는 창과 Gist 동기화 큐에 즉시 반영 | **P0** |
| **FN-EDT-05** | **할 일 상/하 순서 재배치 (Reorder)** | - 항목 호버 시 나타나는 `[▲ 위로 이동]`, `[▼ 아래로 이동]` 버튼으로 할 일의 우선순위와 위치를 즉시 변경 가능 (맨 위 항목은 위로 버튼 비활성화, 맨 아래 항목은 아래로 버튼 비활성화) | **P1** |
| **FN-EDT-06** | **할 일 만료일(날짜) 설정 및 긴급도 배지** | - **단일 통합 날짜 입력**: 별도 텍스트창 없이 단일 날짜 입력 필드에서 마우스 달력 선택 및 키보드 직접 타이핑을 모두 지원<br/>- **연도 4자리 자동 포커스 이동**: `max="9999-12-31"`을 적용하여 연도가 6자리까지 입력되던 Chromium 문제를 수정하고 4자리 입력 완료 시 자동으로 월 입력칸으로 이동<br/>- **긴급도 배지**: 오늘 마감(`오늘`), 지난 기한(`지남`, 붉은 경고색), 미래 기한(`10/15(화)`)으로 자동 서식화 | **P1** |

### 2.4 시스템 라이프사이클 및 동기화 기능 (System Domain)

| 기능 ID | 기능명 | 동작 규격 및 조건 분기 | 우선순위 |
| :--- | :--- | :--- | :---: |
| **FN-SYS-01** | **앱 부팅 & 트레이 상주 라이프사이클** | - **앱 실행 시**: `device-config.json`에 저장된 이전 스티커 창들을 바탕화면에 자동 복원. 저장된 스티커가 0개인 경우 기본 노란색 일반 메모 스티커 1개를 화면 중앙에 자동 생성<br/>- 트레이 우클릭 메뉴: `📝 새 메모 스티커`, `☑️ 새 할 일 스티커`, `👀 모든 스티커 숨기기/보이기`, `🗄️ 아카이브 & 설정 열기`, `🔄 지금 동기화`, `🚀 부팅 시 자동 실행`, `✖ 앱 완전 종료` | **P0** |
| **FN-SYS-02** | **실시간 반응형 Push & ETag Pull** | - **Push**: 버튼 조작(추가/완료/삭제/이동) 시 **300ms 초고속 업로드**, 메모 타이핑 시 **1.5초 디바운스** 후 Gist 증분 `PATCH`<br/>- **Pull**: **창 포커스(클릭) 시 즉시 확인**, 백그라운드 **10초 주기** 폴링, 절전 모드 복귀(`resume`) 시, 네트워크 재연결(`online`) 시 `If-None-Match` 기반 초고속 동기화 | **P0** |
| **FN-SYS-03** | **단일 창 인라인 충돌 병합 (Single-Window Inline Merge)** | - 양쪽 기기에서 동일 스티커를 동시 수정하여 충돌 발생 시, **새 창을 띄우지 않고 기존 단일 창 안에서 인라인 병합**:<br/>  • **일반 메모**: 최신 수정본 하단에 구분선 및 `[⚠️ 기기명 충돌 내용]`을 인라인으로 덧붙여 데이터 유실 방지<br/>  • **할 일**: 두 기기에서 추가한 할 일 항목들을 고유 ID 기준 **합집합(Union)**으로 병합하여 한 창에 통합<br/>  • **초기 동기화 정리**: 최초 Gist 연결 시 로컬의 미작성 기본 빈 스티커는 자동으로 닫아 불필요한 창 중복 방지 | **P0** |
| **FN-SYS-04** | **크로스플랫폼 OS 맞춤 감지 (macOS & Windows)** | - **macOS**: 메뉴바 노란색 포스트잇 아이콘 상주, 독(Dock) 아이콘 클릭 시 `app.on('activate')`로 설정 창 복원, `Cmd+Shift+N/T` 단축키 라벨, `macOS 로그인 시 자동 실행` 표시<br/>- **Windows**: 작업표시줄 시스템 트레이 상주, `Ctrl+Shift+N/T` 단축키 라벨, `Windows 시작 시 자동 실행` 표시 | **P1** |
| **FN-SYS-05** | **네트워크 재연결 시 자동 동기화** | - 오프라인 상태에서 네트워크가 다시 연결되면 브라우저 `online` 이벤트를 감지하여 대기 중인 변경사항을 즉시 Gist와 동기화 | **P1** |
